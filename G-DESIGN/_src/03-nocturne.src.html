Vitrail — 03 · Nocturne

Autre point de vue : on regarde le vitrail du dehors, la nuit. Le monde est monochrome, ardoise et givre ; la seule chaleur sort par les joints du plomb, qui brillent quand le verre est posé, et la couleur coule sur le sol. Pas de serif : une condensée très grasse pour les titres, une mono pour l'interface, rangée dans les coins.
